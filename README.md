# ComputerCraft Programs
A collection of scripts that run on CC: Tweaked Computers, mainly built because I wanted more functionality
Many utilise other mods or custom-built APIs (see Minecraft-MicroServices https://github.com/JacobCroul/Minecraft-MicroServices)

## Getting Started
The scripts can be downloaded using an extremely janky installer, aptly named "updater.lua"
1. ensure `computercraft-server.toml` allows connections to private addresses (wherever you host the APIs)
2. (optional) attach a disk drive and insert a floppy disk, run `cd disk\` to set the disk as active directory
3. run `wget https://github.com/JacobCroul/ComputerCraftPrograms/raw/branch/main/updater.lua` to download the installer
4. run the script, you will be asked to choose between Gitea and Github, select Github
5. find the script you desire and download it
6. You don't need this script anymore (unless you want to see if ive updated it)
